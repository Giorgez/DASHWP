=== DashWP – Custom Dashboard ===
Requires at least: 5.8
Tested up to: 6.6
Requires PHP: 7.4
Stable tag: 1.0.0
License: GPLv2 or later

Replaces the WordPress dashboard with a clean, responsive grid of shortcut blocks.

== Description ==

* Replaces wp-admin's first page with your own shortcut blocks.
* Each block has a name, a link (an admin page, a plugin page or any URL), an icon (Dashicons or Font Awesome Free) and a color.
* Add, edit, delete and drag-and-drop re-order blocks under **DashWP** in the admin menu.
* Optionally show a block only to certain user roles, open it in a new tab, add a short description.
* Hides every admin notice, the welcome panel and all default and plugin dashboard widgets.
* Optionally hides update nags, update counters, footer text, and notices on all admin pages.

== Installation ==

1. Plugins → Add New → Upload Plugin → choose dashwp.zip → Install Now → Activate.
2. Open **DashWP** in the admin menu and add your shortcuts.
